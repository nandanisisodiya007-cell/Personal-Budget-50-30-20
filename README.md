Personal Budget Using the 50/30/20 Rule

1. Project Overview

This project involves creating a monthly budget spreadsheet for a fictional student using the 50/30/20 budgeting rule. It compares planned expenses with actual spending to analyse financial habits and improve savings.

2. Project Objectives

- Understand the 50/30/20 budgeting rule.
- Categorise expenses into Needs, Wants and Savings.
- Compare planned and actual expenses.
- Calculate totals and percentages using Excel formulas.
- Identify overspending through conditional formatting.
- Visualise spending patterns using a pie chart.

3. Monthly Budget Details

Fictional Monthly Income: ₹15,000

Category| Planned Amount| Actual Amount
Needs| ₹7,500| ₹8,100
Wants| ₹4,500| ₹5,200
Savings| ₹3,000| ₹1,700
Total| ₹15,000| ₹15,000

4. Excel Functions and Tools Used

- SUM() – Calculates total expenses.
- SUMIF() – Calculates totals based on categories.
- Percentage Formula – Calculates each category's share of income.
- Conditional Formatting – Highlights overspending.
- Pie Chart – Displays the distribution of actual spending.

5. Key Findings

- Needs accounted for 54% of income.
- Wants accounted for 35% of income.
- Savings accounted for only 11% of income.

The actual spending on Needs and Wants exceeded the planned budget, resulting in lower savings.

6. Recommendations

1. Reduce unnecessary subscriptions and avoid unnecessary expenses.
2. Set a monthly limit for shopping and outings.
3. Transfer a fixed amount into an emergency savings fund immediately after receiving income.

7. Project Files

- personal_budget_50_30_20.xlsx – Monthly budget spreadsheet.
- budget_chart.png – Visual representation of the budget distribution.

8. Tools Used

- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Data Visualisation

9. Conclusion

This project demonstrates how Microsoft Excel can be used for monthly budget planning and financial analysis. Following the 50/30/20 rule can help individuals control expenses, manage money effectively and develop better saving habits.
